Un proyecto en el que utilizo como backend Spring-Boot y como frontend Angular, muy equilibrado, metiendo librerias para tener las seguridad máxima posible dentro de la página web.
La página web del servidor esta conectada a una base de datos relacional llamada MySQL en donde las tablas tendrán entre ellas relaciones clave primaria de una tabla con clave foránea de otra, datos fijos de 
autoincremento... etc
