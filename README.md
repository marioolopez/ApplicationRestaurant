Un proyecto en el que utilizo como backend spring-boot y como frontend angular, muy equilibrado, metiendo librerias para tener las seguridad maxima posible dentro de la pagina web.
La página web del servidor esta conectada a una base de datos relacional llamada MySQL en donde las tablas tendran entre ellas relaciones clave primaria de una tabla con clave foranea de otra, datos fijos de 
autoincremento... etc
